# Notchware Releases

Official downloads for **Notchware**, a macOS app that makes your MacBook notch useful, by [Ballmac](https://ballmac.com).

**[Download the latest Notchware for macOS](https://github.com/vamsiy78/notchware-releases/releases/latest/download/Notchware-macOS.dmg)**

- Learn more: https://ballmac.com/notchware
- Requires macOS 14.6 Sonoma or later

## Install

1. Download `Notchware-macOS.dmg` from the [latest release](https://github.com/vamsiy78/notchware-releases/releases/latest).
2. Open it and drag **Notchware** to the Applications folder.
3. Open Notchware from Applications. macOS asks you to allow it once: click **Done**, then open **System Settings → Privacy & Security** and choose **Open Anyway**. [Step-by-step install guide](https://ballmac.com/notchware/install).

This repository only hosts release builds. Check for Updates in Notchware reads its public list of releases.
